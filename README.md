# SpEx Simulator

* Space Expedition Simulator is an interactive space expedition simulator designed to simulate missions and monitor fleet status in real time;
* Architecture: The project is built on the modern React library, with an emphasis on a component approach and interface scalability
* Core Features:
  * Mission Filtering: A dynamic mission filtering system has been implemented for quick selection of the desired flight parameters;
  * Ship Status Dashboard: Interactive components that display the current status of spacecraft (fuel level, hull integrity, crew).   
* State Management: Effective application state management for smooth data updates without unnecessary re-rendering;
* Routing: Navigation between different simulator modules has been configured, allowing the user to smoothly switch between fleet overview and detailed mission planning.

# Poliomino

* Poliomino Game is a puzzle game designed with a focus on performance and an effective combination of different programming languages;
* Core Engine: Game logic and computational core implemented in C++ to achieve maximum execution speed and processing of game mechanics;
* Architecture: The pybind11 library was used to create a highly efficient interface between the C++ core and Python scripts responsible for the high-level logic of the application;
* Features: Implemented a level system, background resource loading, audio, and PvP mode for playing with AI;

# New Year Gift App


* New Year Gift App — a desktop application for convenient management of gift sets and assortment of sweets;
* Architecture & UI: Developed in Java using the JavaFX framework. The interface is implemented declaratively via FXML, which ensures a clear separation of logic and visuals;
* Database & Integration: Integrated SQL database to store structured data about gifts, their composition and characteristics;
* Build System: Dependency management and project lifecycle automated using Apache Maven.

# Link Parser 

* LinkParser is a Telegram bot designed for fast, automated formatting of regional links into ready-to-publish HTML templates for Telegram channels; 
* Core Functionality: Allows users to parse raw lists of cities and URLs, automatically mapping standard city names to specific regional variations and wrapping them into 5 distinct visual templates featuring custom and premium emojis; 
* Architecture: The project is built on Python using the pyTelegramBotAPI (telebot) library, ensuring fast text processing and seamless generation of HTML-formatted messages with Telegram Bot API integration; 
* State Management: Utilizes an efficient in-memory state tracking system to remember the user's selected formatting template per chat session, allowing for continuous batch processing of links without re-selecting settings; 
* Efficiency: Features an intuitive user interface with a persistent custom Reply Keyboard for one-click template switching, automating repetitive text formatting tasks and significantly reducing the time required by content managers to prepare posts.
